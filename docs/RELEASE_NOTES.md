# 泥石 1.0.0

泥石的首个公开源码版本，提供课程表、教务学习工具、学习通通知与校园生活服务。

- **课程表**：教务登录导入、周次切换、课程详情、离线缓存、手动排课、课程笔记与桌面组件。
- **学习**：成绩查询、学业生涯、考试信息、通知消息、已选课程、板块课与 PDF 导出；大一尚无成绩时显示空状态，不填充模拟成绩。
- **教务账户**：统一从「我的 → 校园服务账户」登录，复用本地加密会话；不再提供个人信息工具。
- **学习通通知**：作业与考试待办归并、课表异动识别、通知原文、搜索与本地归档。
- **服务**：喝水、洗衣、宿舍电费三个并列入口；电费复用初始化保存的教务学号，不重复输入或绑定学号。
- **隐私与安全**：账户凭据沿用 Android Keystore + AES-GCM 保存在本机；禁止系统备份，限制教务 WebView 仅访问学校 HTTPS 主页面。
- **构建**：Kotlin、Jetpack Compose、Material 3；Debug 和离线 Demo 变体均可从源码构建。

## 验证

- `testDebugUnitTest`：128 项，127 通过、0 失败、1 跳过；跳过的是未提供账号的既有学习通联调用例。
- `assembleDebug`、`assembleDemo`：通过。
- 真实教务、学习通、电费、短信、支付和设备控制依赖相应账户、权限、校园网络与现场设备，未在本机完成全部真机联调。

## 安装与使用

运行环境为 Android 8.0（API 26）及以上。正式安装包需要自行配置签名；签名密钥、本机服务配置和账户数据不应提交到仓库。
